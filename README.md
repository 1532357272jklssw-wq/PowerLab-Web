# PowerLab Web

PowerLab 电源与硬件工程师面试题库的 PWA 网页版。

## 功能

- 8 个硬件与电源专业分类
- 分类刷题与详细解析
- 专业术语和参考来源
- 错题本与学习进度
- JSON 题库导入和联网更新
- 离线缓存和手机主屏幕安装

## GitHub Pages

将本目录的全部内容上传到公开 GitHub 仓库的 `main` 分支，在 `Settings -> Pages` 中选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

题库数据位于 `data/question-bank.json`。
